BETPREDICT AI — versão inicial de demonstração

Esta é uma primeira interface web instalável (PWA).
Os jogos e percentagens são EXEMPLOS FICTÍCIOS. Não são resultados em direto,
não são previsões produzidas por IA e não devem ser usados para apostar.

Publicação gratuita com GitHub Pages:
1. Crie um repositório público chamado betpredict-ai.
2. Carregue os três ficheiros: index.html, manifest.webmanifest e sw.js.
3. No repositório, abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch main e a pasta /(root), depois Save.
6. Aguarde a publicação. O endereço será https://NOME-DE-UTILIZADOR.github.io/betpredict-ai/

Para instalar no iPhone:
1. Abra o endereço publicado no Safari.
2. Toque em Partilhar.
3. Escolha Adicionar ao ecrã principal.
